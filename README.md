# 搬瓦工 VPS 选购与入门指南：从套餐到首次连接

搬瓦工（BandwagonHost）提供 VPS 服务。可以把 VPS 理解为一台由服务商托管、通过网络远程管理的虚拟服务器：它可用于学习 Linux、运行网站或部署应用，但购买服务器并不等于获得一个已经配置好的网站。选择系统、安装软件、保管访问凭据和维护数据，仍需要使用者自己处理。

这份指南面向正在比较搬瓦工套餐、准备下单或首次登录服务器的读者。选购前先想清楚三件事：运行什么软件、访问者主要在哪里，以及能投入多少预算和维护时间。不同场景对内存、流量和网络的要求不同，不能只看价格或某个线路名称做决定。

## 机房与线路如何判断

机房是服务器所在的位置，线路则描述数据往返网络的路径。位置接近访问者值得考虑，但不保证连接一定更快；运营商、路由、访问时段和本地网络状况也会影响结果。参考资料提到洛杉矶 DC6/DC9、日本大阪软银和荷兰 AS9929 等方向，可结合目标套餐实际提供的选项进行比较。

如果服务商提供机房测试 IP，可以在访问者常用的网络和时段做延迟测试，并结合路由、连接情况观察。尽量分别记录测试对象、时间和网络环境，避免把不同条件下的一次结果直接比较。测试结果只反映当时的情况，不是未来速度或稳定性的承诺。

机房迁移也是选择时的重要条件，但不是所有套餐都能迁到所有位置。购买前看产品说明，购买后再核对 KiwiVM 中实际显示的目标机房；如果某个地点对业务不可或缺，不应仅凭其他套餐的说明推断它一定可选。

## 首次登录搬瓦工控制面板

参考资料中的入口为账户内的 **Services → My Services → KiwiVM Control Panel**。进入对应服务后，可在 KiwiVM 查看服务器信息，也可使用面板提供的开关机、流量查看、系统重装等管理功能。操作前确认选中的是正确的 VPS，尤其是账户中有多台服务时。

### 找到连接信息并使用 SSH

1. 在 KiwiVM 主页面查看 **IP Address** 和 **SSH Port**。SSH 是远程登录服务器的方式；端口以面板实际显示为准，不要假定一定是 22。
2. 准备登录凭据。参考资料中的 root 密码重置路径是左侧 **Root password modification**：先关闭 VPS，再生成新密码。按面板提示操作，并及时、安全地保存新密码。
3. 在电脑终端或 SSH 客户端中，使用自己的实际 IP 和端口连接。命令格式如下，将尖括号中的内容替换为面板显示的值：

   ```bash
   ssh root@<服务器IP> -p <SSH端口>
   ```

   其中 `root` 是登录用户名，`-p` 后面指定 SSH 端口。首次连接时，根据终端提示核实主机身份并输入凭据；密码输入过程中通常不会显示字符。
4. 如果连接失败，先核对 IP、端口、凭据和服务器运行状态，再检查本地网络。无法从本地连接时，可尝试面板中的 **Root shell - interactive** 应急入口，检查服务器状态和配置。

连接成功只是开始。使用 root 权限时应谨慎执行操作，妥善保存密码；如计划改用密钥登录，先了解密钥保管与访问恢复方法，避免失去管理入口。

## 系统部署、迁移与备份

参考资料提到 Debian、Ubuntu 和 CentOS 等 Linux 发行版。选择时应查看当前面板提供的镜像，并确认目标软件支持的系统版本和维护状态。学习 Linux 可以从文件操作、权限、软件安装和服务管理入手；建站则需要考虑网站程序、数据库及运行环境。

图形管理面板和 LNMP 是资料中提到的两种建站环境选择：前者以图形界面管理为主，后者通常通过命令行部署。选用前先阅读相应软件的安装和安全说明，确认系统版本兼容。部署应用时，应查其实际资源需求，再与套餐内存、磁盘和其他同时运行的服务一起核算，不能把某一应用的最低需求当成所有项目都适用的标准。

**重装系统会清空原有数据。**操作前应把网站文件、数据库及其他重要资料备份到服务器之外，并确认可以读取和恢复。KiwiVM 提供快照和备份相关功能，但使用前要核对当前套餐和面板中的具体条件；不要把单一快照当作唯一的数据保障。

如果套餐支持机房迁移，可在 KiwiVM 查找 **Migrate to different datacenter**，查看可选目标与提示。确认前先备份重要数据，核对目标机房及迁移条件；完成后检查服务和访问是否正常。日常也应查看面板中的流量统计，结合自己的使用量安排资源，避免临近限额才发现流量不足。

## 常见问题

### 套餐价格和库存为什么要在下单前再看？

参考表格是特定资料中的价格，不是实时报价。产品可能缺货，计费周期、促销和续费条件也可能变化；确定预算时，应以对应产品及结账页面的当前信息为准。

### 可以随时换到任意机房吗？

不能据此一概而论。迁移能力取决于具体套餐和当前可选机房。先在产品说明及面板核实目标是否可选，再备份数据并阅读迁移提示。

### SSH 端口和重装前的备份在哪里处理？

端口查看 KiwiVM 主页面的 **SSH Port**；重装之前，先将所需数据备份到服务器之外并确认恢复方式。面板中的快照、备份和系统操作可辅助管理，但执行前仍需确认当前功能和提示。
