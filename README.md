# 搬瓦工 VPS 入门与选购指南

搬瓦工（BandwagonHost）提供 VPS 主机服务。VPS 可以理解为一台由服务商托管、通过网络远程管理的虚拟服务器。购买之后，通常需要在管理面板查看服务器信息，再通过 SSH 登录，安装或配置自己需要的系统与应用。这篇指南从用途判断、套餐比较到首次连接，按实际决策顺序整理相关信息，适合第一次接触搬瓦工、希望先弄清购买和管理流程的读者。

VPS 并不是购买后就自动成为网站或应用：系统维护、软件配置、账号安全和数据备份仍需要使用者处理。选套餐前，先确认自己愿意投入多少管理时间，以及服务器实际要承载什么工作。

## 先明确用途，再决定需要什么

不同用途对资源和网络的侧重点并不相同。不要只根据套餐名称或单一参数判断是否合适，可以先列出预期运行的程序、预计访问来源，以及能够接受的维护复杂度。

- **学习 Linux 或熟悉服务器管理：**重点是有一台可远程登录、可以练习系统操作的 VPS。入门配置可用于了解 SSH、用户权限、软件安装等基础，但实际能否运行某个程序仍取决于其资源需求。
- **个人网站或小型项目：**除了 CPU 和内存，也要考虑磁盘空间、月流量及备份安排。网站程序、数据库和访问量会共同消耗资源；不要把“可以购买”理解为任何负载都能稳定运行。
- **部署应用：**先查清应用自身对操作系统、内存、磁盘和依赖环境的要求，再对照套餐配置。参考资料列出的套餐规格只是产品信息，不等于对具体应用性能的保证。
- **在意中国大陆访问路径：**需要把线路类型和目标机房纳入比较。CN2 GIA-E、香港或日本线路属于不同产品选择，实际体验受所在地、运营商、时段和网络状况影响，不宜仅凭线路名称推断访问结果。

也要考虑管理方式：Linux 服务器通常通过命令行维护。若不熟悉命令行，可以先学习基本连接和安全操作，再部署网站或应用；购买 VPS 本身不会代替后续配置。

## 购买与注册：下单前后的检查

参考资料中的购买流程是通过产品页面选择方案并注册账号。界面内容可能调整，操作时以页面提示为准。下单前先核对方案名称、配置、付款周期和订单金额；如果有机房选项，也应确认它是购买时的选择，还是购买后通过面板可变更的项目。

1. 打开与目标方案对应的套餐页面，核对当前展示的规格、价格和周期。确认链接对应的是想购买的方案，不要因相邻产品名称相似而忽略差别。
2. 按结账流程注册或登录账号。使用自己能够持续访问的邮箱，并检查账号资料与订单信息是否正确，以便接收服务通知和登录管理账户。
3. 在付款前复核购物车中的产品和周期，仔细查看页面提供的付款方式及相关条件。参考资料提及支付宝，但可用方式可能因订单或页面状态而不同，应以结账页实际选项为准。
4. 完成订单后保存账号和订单相关信息。随后从账户中的服务列表进入对应 VPS；服务开通和连接所需的具体信息，以账户面板显示为准。

如果购买后考虑换机房，先确认该方案是否提供相应选项，不必仅凭购买页面的默认位置推断长期可用的迁移范围。

## KiwiVM 与首次 SSH 连接

KiwiVM 是参考资料所述的 VPS 管理面板入口。通常从账户的服务列表找到 VPS，再进入对应的 KiwiVM Control Panel。连接前要准备服务器 IP、SSH 端口和登录凭据；SSH 端口应以面板显示为准，不能假设一定是默认的 22。

连接步骤如下：

1. 在 KiwiVM 主页面查看 IP Address 与 SSH Port，并确认要登录的实例。
2. 准备 root 密码或已配置的 SSH 密钥。首次连接前确认本地终端可用；macOS 和 Linux 可使用系统终端，Windows 可使用 PowerShell、Windows Terminal 或其他 SSH 客户端。
3. 在终端输入下列格式，将示例占位内容替换为面板中的实际信息：

   ```bash
   ssh root@你的IP地址 -p 你的SSH端口
   ```

4. 首次连接时按终端提示确认主机身份，再输入凭据。输入密码时终端通常不会显示字符，这是正常的交互方式；如果连接失败，先逐项核对 IP、端口、凭据以及实例状态。

参考资料指出，KiwiVM 的 Root password modification 可用于生成或重置 root 密码，并要求先关闭 VPS。重置前确认自己确实需要更换凭据；生成后立即妥善保存新密码，避免丢失。若本地 SSH 暂时无法使用，面板中的 Root shell - interactive 可作为浏览器内的管理入口；它是应急访问途径，不应取代日常凭据管理。

## 系统初始化与部署前准备

连接成功后，先确认系统发行版、登录身份和当前服务状态，再开始安装软件。参考资料提到可选 Debian、Ubuntu、CentOS 等发行版，但不同镜像和版本的实际可用列表可能变化。选择前应考虑目标软件支持哪些系统版本、系统维护周期以及自己的操作经验，不能只按熟悉程度决定。

正式部署前，建议先完成这些准备：

- **明确用途与软件依赖。**列出要运行的网站、数据库或其他程序，核对它们支持的操作系统与资源要求。
- **保护访问凭据。**保存必要的登录信息，避免把密码公开或重复用于不相关服务。是否改用 SSH 密钥，可在理解密钥管理和恢复方式后再配置。
- **先规划数据与恢复。**区分可重新安装的软件与不可丢失的数据，安排独立的备份方式，并确认自己知道如何恢复。
- **控制部署范围。**先部署必需组件，逐步验证服务运行情况；出现问题时更容易判断是系统、依赖还是应用配置导致。

建站者还需要考虑域名、网站程序、数据库和网站数据的备份；部署应用者应确认应用的资源需求和运行方式；学习 Linux 的用户则可以从文件操作、权限和服务管理等基础内容开始。参考资料没有给出适用于所有用途的安装命令，因此这里不提供可能与系统版本或应用配置不匹配的一键命令。

## 机房选择与迁移

机房并非只按地图距离选择。运营商、目标用户所在地、线路和访问时段都可能影响连接质量。对中国大陆访问者而言，可以把产品页面标注的线路类型与本地测试结果一起比较；有条件时，使用对应机房的测试信息进行延迟或路由测试，观察与自己实际网络的相关性。单次测试只能反映当时状况，不应视为未来速度或可用性的保证。

如果套餐支持迁移，可在 KiwiVM 中查找 **Migrate to different datacenter**，查看当前可选数据中心，再根据目标用途选择。确认之前先检查面板提示和迁移条件，并为重要文件准备独立备份。不要因为参考资料提到迁移就假设所有套餐都能迁移到所有地点，也不要把迁移时长或数据保留当作保证；以当前面板说明为准。

## 日常维护与常见问题

### SSH 端口在哪里查看？

在 KiwiVM 主页面查看 SSH Port，并使用该端口连接。即使过去配置过某个端口，也应以当前实例显示的信息为准。若无法连接，可检查 IP、端口、实例状态、网络环境及凭据，再逐项排除。

### 重装系统会保留文件吗？

不要假设会保留。重装可能清除原有系统和数据；操作前将需要保留的文件备份到 VPS 之外，并确认备份能够读取。重装后还要重新配置应用和访问方式。面板是否提供快照、快照条件和可用性可能变化，操作前查看当前说明，不要把快照当作唯一备份。

### 流量和服务状态如何检查？

可在 KiwiVM 中查看面板提供的资源或流量信息，并关注服务状态。不同界面的菜单和统计方式可能调整；若应用访问异常，也要分别检查 VPS 状态、应用进程和本地网络，而不是只凭一个指标判断原因。

### 购买前最容易忽略什么？

常见遗漏包括只看首期价格、没有核对付款周期、误认为线路名称代表固定体验，以及没有计划备份和系统维护。把当前页面的价格、配置、迁移范围和条款逐项核实，比依靠过往促销信息或笼统推荐更可靠。

## 最后用五项检查作决定

准备购买时，先写清楚 VPS 的用途和软件需求；再比较配置、流量和预算；如果网络路径重要，结合目标地区和测试结果看线路；接着确认该产品的可迁移范围与管理要求；最后复核价格、付款周期和页面条款。需要浏览产品时，可通过[查看全部在售套餐](https://bwh81.net/aff.php?aff=85082)进入总览，并从相应产品入口核对当前信息。购买后先保存登录资料、完成首次 SSH 连接，再安排系统初始化与数据备份。这样能把选购和后续维护都纳入同一套判断，而不是只关注下单这一步。
